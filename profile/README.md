<h2>一、先把「不用会怎样」拆成四层看</h2>
<p>把问题摊平，四个层其实各自独立结算。网络层决定平台第一眼看到的地址属性；会话层决定同一个号前后两次登录像不像同一个人；账号层决定一个号出事会不会把同批号一起拖下水；预算层决定这套东西一个月要付出去多少。四层里任何一层塌了，上面几层都白做。所以先别急着看别人推荐什么型号，先找出自己最短的那块板。</p>
<p>顺序上也有讲究。网络层是可测的，十分钟能出结果；会话层要靠几天观察；账号层要等真出事才知道；预算层最容易被忽略，却往往是最后让人半途换服务商的原因。按这个顺序排查，能少走不少回头路。</p>

<h2>二、网络层：机房段和家宽段差在哪儿</h2>
<h3>ASN 与登记归属地要对得上</h3>
<p>最直接的两个查询入口是 ipinfo.io 加出口 IP，以及 ipapi.is，前者看 asn 与 org 字段，后者看 is_datacenter 与 is_vpn 两个布尔值。家宽出口的 ASN 一般挂在 Comcast、Verizon、AT&amp;T、Deutsche Telekom 这类运营商名下，org 里不会冒出 Amazon、DigitalOcean、Vultr、Hetzner 这些名字。判定阈值可以自己钉死：org 命中常见云厂商名单就直接判不合格，不用再往下看延迟和带宽。</p>
<h3>同段邻居的密度比单条 IP 更能说明问题</h3>
<p>24 位掩码内活跃主机的数量很能说明问题。机房段一个 /24 塞进几百个客户是常态，家宽段通常只有几十个活跃地址。挑十几个邻居地址做端口抽样，如果大量常见端口开放、响应时间又高度雷同，基本可以断定是共享机房段。这一步十分钟，能省掉后面反复换服务商的折腾。</p>

<h2>三、会话层：老号一条线、新号另一条线</h2>
<h3>为什么必须按号的新老分线</h3>
<p>老号有历史登录记录，平台手里握着一条基线：常用城市、常用设备、常用时段。突然换到另一个国家或者另一个 ASN，等于自己把基线推翻。新号没有基线，第一次落地在哪儿，后面就默认以那儿为准。两者的容错空间完全不同，所以老号优先保稳定、新号优先保干净，这两件事不该挤在同一条出口上做。</p>
<h3>分线落到操作上是三个动作</h3>
<p>最省事的做法是按账号建档：一个号一行，写上分配的出口 IP、ASN、城市、时区、首次登录时间。老号只在原城市内换 IP，尽量不动 ASN；新号一次性锁定一个城市，从注册那天起不跳区。执行时用两个独立的浏览器配置目录，或者干脆两台机器，别在同一个浏览器里来回切代理，cookie 和本地存储会互相污染。</p>

<h2>四、账号层：风险不串需要几条硬约束</h2>
<h3>四条约束，中两条就够被归组</h3>
<p>风险串联通常不是平台主动去做，而是自己凑出来的：同一个出口、同一个浏览器指纹、同一批注册时间、同一套支付方式，四条里中两条，几个号就会被归到一组。要断开这种关系，最有效的往往不是换 IP，而是让每个号在可观测的维度上都长得不一样。</p>
<p>出口不共用，一条出口只挂一个主号，副号另开；指纹不共用，时区、语言、字体列表、Canvas 结果各自不同，用指纹检测页自查；支付不共用，同一种支付方式绑太多号，关联度比 IP 还高；时间不共用，同一分钟批量注册十几个号这个模式本身就很显眼，摊到几天里做完更自然。</p>
<h3>「另开出口」不等于每次都换</h3>
<p>不少人把它理解成每注册一个号就换一次 IP，结果反而制造了异常。正确理解是：新号从第一次落地起就固定一条专属出口，之后不再变动。变动本身是信号，稳定才是目的。</p>

<h2>五、预算层：不频繁换服务商的钱怎么算</h2>
<p>换服务商的成本从来不只是差价。一次迁移平均要花半天到两天：重新选型、开通道、逐号换出口、观察一周、处理掉线。按一个人日成本算，折腾一轮就是几百到上千元，比月费差价高出不少。所以选型时把「能不能长期用」放在「这个月便宜多少」前面，通常更划算。</p>
<p>价格区间仅供参考：按量计费的家宽出口大致在每 GB 几元到二十几元，包月按账号算大致每条每月几十到一两百元，独享静态住宅普遍再贵一档。这些数字随地区和供应商波动很大，签之前一定要拿一两条实测，别照报价单做预算。</p>

<h2>常见问答</h2>
<h3>不用住宅 IP 一定会被封吗？</h3>
<p>答：不会。是否触发限制取决于出口属性、会话一致性、请求频率和账号历史共同作用，住宅出口只是把其中一项拉回正常水平。把它当成降低概率的手段，而不是保证。</p>
<h3>老号换到新出口要注意什么？</h3>
<p>答：尽量只换 IP 不换城市和 ASN，换完头两天把请求频率压到平时的一半，观察有没有验证码或二次验证，稳定之后再恢复原节奏。</p>
<h3>一条出口能挂几个号？</h3>
<p>答：主号一条独占最稳。预算紧可以两三个低频号共用，但要接受被牵连的可能，共用期间别在同一时段集中登录。</p>
<h3>怎么判断换服务商是真的换对了？</h3>
<p>答：记录迁移前后各两周的异常次数、验证码出现率、掉线时长三项，用同一套口径对比。三项里有两项明显下降，才算换对。</p>
